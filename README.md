Shadow Architect is an original 2D optical puzzle: arrange objects and a point light so their real-time shadows form the target silhouette. It ships with a menu and a Chapter I tutorial level, plays with keyboard, mouse, or touch, and features procedural WebAudio music. No network, no build step — just static files in your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play at `/game/index.html`.

Alternatively, open `game/index.html` directly in a desktop browser.
